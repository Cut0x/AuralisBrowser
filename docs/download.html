Configuration requise

Composant Minimum Recommandé
OSWindows 10 (1903+)Windows 11
Architecturex86-64x86-64
RAM2 GB4 GB
Stockage50 MB100 MB
WebView2 Runtime requis Intégré à Windows 11
WebView2 est pré-installé sur Windows 11. Pour Windows 10, il sera téléchargé et installé automatiquement.

Installation en 3 étapes

1
Télécharger le fichier
Cliquez sur « Télécharger .exe » ci-dessus pour obtenir Auralis_0.2.0_x64-setup.exe.
2
Lancer l'installateur
Double-cliquez sur le .exe. Windows peut demander une confirmation UAC — c'est normal.
3
Choisir votre langue
Choisissez FR ou EN. Auralis se lance automatiquement.
