Installer Auralis

Gratuit, open source, propre à désinstaller.

Système détecté
Windows 10 / 11
Auralis v0.1.0 · 64-bit
Télécharger le setup (.exe)

Nécessite Windows 10 64-bit · WebView2 Runtime (inclus dans Windows 11)

MSI (entreprise) Code source

Configuration requise

Composant Minimum Recommandé
OSWindows 10 (1903+)Windows 11
Architecturex86-64x86-64
RAM2 GB4 GB
Stockage50 MB100 MB
WebView2 Runtime requis Intégré à Windows 11

WebView2 est pré-installé sur Windows 11. Pour Windows 10, il sera installé automatiquement si absent.

Installation en 3 étapes

1

Télécharger le fichier

Cliquez sur le bouton ci-dessus pour obtenir Auralis_0.1.0_x64-setup.exe

2

Lancer l'installateur

Double-cliquez sur le .exe. Confirmez l'UAC si demandé.

3

Choisir votre langue

L'installateur vous propose FR ou EN. Auralis se lance à la fin.
